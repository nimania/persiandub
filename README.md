# PersianDub Mobile — دوبله زندهٔ فارسی روی اندروید

نسخهٔ اندرویدِ همان ایده: صدای دستگاه را می‌گیرد، با **Gemini Live Translation**
زنده به فارسی ترجمه می‌کند و صدای فارسی را پخش می‌کند. همان موتور نسخهٔ دسکتاپ،
با همان کلید Gemini API.

دو منبع صدا دارد و در خود اپ قابل انتخاب است:

- **صدای داخلی دستگاه** (MediaProjection): کیفیت بالا و بدون اکو. برای صدایی که در
  **مرورگر موبایل** پخش می‌شود عالی کار می‌کند. توجه: خودِ اپ یوتیوب ممکن است اجازهٔ
  ضبط صدایش را ندهد؛ در آن صورت یوتیوب را در مرورگر باز کنید یا از حالت میکروفون استفاده کنید.
- **میکروفون**: با هر اپی کار می‌کند (حتی خود اپ یوتیوب)، ولی کیفیتش کمتر است و
  **حتماً باید هدفون بزنید** تا صدای پخش‌شده دوباره وارد میکروفون نشود.

## گرفتن فایل APK — دو راه

### راه ۱: بدون نصب هیچ‌چیز، با GitHub Actions (پیشنهادی)

این پروژه یک workflow آماده دارد که APK را روی سرور رایگان گیت‌هاب می‌سازد.

1. یک اکانت گیت‌هاب بسازید (اگر ندارید).
2. یک repository جدید بسازید و این پوشه را در آن آپلود/پوش کنید
   (روی گیت‌هاب می‌توانید مستقیم فایل‌ها را Upload کنید).
3. به تب **Actions** بروید؛ workflow «Build APK» خودکار اجرا می‌شود
   (یا با دکمهٔ **Run workflow** دستی اجرایش کنید).
4. بعد از چند دقیقه، وارد آن run شوید و از بخش **Artifacts** فایل
   `PersianDub-debug-apk` را دانلود کنید. داخلش `app-debug.apk` است.

### راه ۲: با Android Studio

1. پوشه را در **Android Studio** باز کنید (Open).
2. بگذارید Gradle sync تمام شود (اولین بار SDK لازم را خودش می‌گیرد).
3. منوی **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. APK ساخته‌شده در `app/build/outputs/apk/debug/app-debug.apk` است.

## نصب APK روی گوشی

1. فایل `app-debug.apk` را روی گوشی منتقل و باز کنید.
2. اگر پیام «Install from unknown sources» آمد، اجازه بدهید.
3. اپ PersianDub نصب می‌شود.

> چون APK «دیباگ» و بدون امضای رسمی است، فقط برای استفادهٔ شخصی خودتان است،
> نه انتشار در فروشگاه.

## استفاده

1. اپ را باز کنید، کلید **Gemini API** را وارد کنید
   (رایگان از <https://aistudio.google.com/apikey>).
2. زبان مقصد را «فارسی» بگذارید و منبع صدا را انتخاب کنید.
3. **شروع دوبله** را بزنید:
   - حالت «صدای داخلی»: یک بار پنجرهٔ مجوز ضبط صفحه می‌آید؛ **Start now** را بزنید.
   - حالت «میکروفون»: مجوز میکروفون را بدهید و هدفون بزنید.
4. حالا صدایی پخش کنید (مثلاً یوتیوب در مرورگر). بعد از ۲–۵ ثانیه صدای فارسی می‌آید.
5. برای توقف، دوباره دکمه را بزنید (یا از روی نوتیفیکیشن «توقف»).

## ساختار پروژه

| فایل | نقش |
|------|-----|
| `MainActivity.kt` | رابط کاربری، تنظیمات، و گرفتن مجوزها (میکروفون / ضبط صفحه). |
| `DubService.kt` | سرویس فورگراند؛ ضبط صدا (MediaProjection یا میکروفون)، پخش خروجی با AudioTrack. |
| `GeminiClient.kt` | کلاینت WebSocket برای Gemini Live (حالت ترجمه). |
| `AudioUtils.kt` | تبدیل PCM16 ↔ base64. |
| `.github/workflows/android.yml` | ساخت خودکار APK روی گیت‌هاب. |

صدا با نرخ ۱۶ کیلوهرتز مونو گرفته و فرستاده می‌شود؛ صدای فارسی با ۲۴ کیلوهرتز
برمی‌گردد و پخش می‌شود — دقیقاً مثل نسخهٔ دسکتاپ.

## ⚠️ نکتهٔ preview (مثل نسخهٔ دسکتاپ)

مدل ترجمهٔ زنده هنوز preview است. اگر خطای اتصال گرفتید (مثلاً close code 1007)،
در `GeminiClient.kt` دو چیز را با مستندات روز تطبیق دهید: **نام مدل** (`model`)
و ساختار پیام **`setup`** (به‌ویژه `translationConfig` که باید داخل
`generationConfig` باشد).
مرجع: <https://ai.google.dev/gemini-api/docs/live-api/live-translate>

## محدودیت‌ها و نکات صادقانه

- صدای اصلی هم‌زمان پخش می‌شود؛ برای شنیدن بهتر دوبله، صدای منبع را کم کنید.
- حالت میکروفون بدون هدفون دچار اکو/فیدبک می‌شود.
- اپ یوتیوب رسمی ممکن است اجازهٔ ضبط صدای داخلی ندهد؛ راه‌حل: یوتیوب در مرورگر،
  یا حالت میکروفون.
- این APK دیباگ است و برای تست شخصی؛ برای انتشار باید نسخهٔ release امضاشده ساخت.
